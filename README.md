# X-Men Character Showcase

A static website built to showcase X-Men characters through a card-based UI.

## About
A multi-page static site that lets users browse X-Men characters in a 
clean grid layout, view detailed character bios, read about the project's 
theme, and fill out a form to add a new character. Built to practice 
semantic HTML structure, CSS layout techniques

## Notes
This is a static front-end project; the search bar and character form 
are UI elements without backend logic or data storage (planned for the 
semester-long follow-up project).
